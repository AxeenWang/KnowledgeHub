## 1. 先掌握遊戲節奏

主要循環是「採集 → 製作 → 建立補給據點 → 探索 → 擊敗首領 → 取得新材料與工具」。不同生態域的難度差距很大，不必一開始就往遠處走。遊戲支援單人與合作，建屋、料理和整備也是推進的一部分。[官方 FAQ](https://www.valheimgame.com/faq/)

第一次開局建議先用一般設定。若死亡取物或戰鬥壓力妨礙學習，可在世界選擇介面的 **World Modifiers** 調整戰鬥、死亡懲罰等項目。多人世界先與同伴確認設定，本文的掉落與取物說明以一般死亡懲罰為準。[世界調整選項](https://valheim.fandom.com/wiki/World_Modifiers)

前期先完成三件事：**有安全復活點、能穩定吃三種食物、能修理裝備**。完成後再準備首領戰，比急著遠征更容易掌握節奏。這是本文建議的入門順序。

## 2. 第一天照這個順序做

下列順序以建立第一間可用小屋為目標，不要求在固定時間內完成。

| 順序 | 要做的事 | 完成時應有的結果 |
| --- | --- | --- |
| 1 | 閱讀出生點附近的提示，與烏鴉互動，查看首領定位符文石。 | 知道起點與第一位首領的位置。 |
| 2 | 撿樹枝、石頭、莓果和蘑菇，遇到新材料先拾取。 | 背包有基本建材和可吃的食物。 |
| 3 | 在背包製作石斧、木棒和建築用槌子（Hammer）。 | 能砍木、應付小型敵人並開啟建築選單。 |
| 4 | 留在青青草原，選擇容易辨識、附近有木材的位置放工作臺。 | 有第一個製作與建築據點。 |
| 5 | 為工作臺補牆面與屋頂，建床、營火及箱子。 | 工作臺可使用，床已認領為復活點。 |
| 6 | 在火上放烹飪架（Cooking station），烤熟取得的肉。 | 有熟食，也知道如何補充營火燃料。 |
| 7 | 吃東西、休息並修理裝備，天黑時回屋整備。 | 可以帶著補給開始下一次探索。 |

配方通常在你發現所有必要材料種類後才解鎖。看不到某件裝備時，先確認材料是否親手拿過，再檢查製作站及等級需求。[入門機制](https://valheim.fandom.com/wiki/How_to_play)、[製作選單](https://valheim.fandom.com/wiki/Crafting_menu)

前期可沿水邊找燧石（Flint），狩獵野豬取得皮革碎片、狩獵鹿取得鹿皮與鹿肉。先把工具、小盾和基本防具補齊，不必一次製作所有武器。鹿容易逃跑，可以用粗弓（Crude bow）與木箭練習狩獵。[材料分類](https://valheim.fandom.com/wiki/Materials)、[鹿](https://valheim.fandom.com/wiki/Deer)

## 3. 食物、休息與體力

### 食物決定你有多少生存空間

不吃東西不會因飢餓直接死亡，但食物會提高生命、體力等數值，並提供生命回復。可以同時維持 **三種不同食物** 的效果，同一種食物不能佔兩格。效果會隨消化逐漸衰退，圖示閃爍時可補吃同種食物。[官方食物說明](https://www.valheimgame.com/faq/)、[食物機制](https://valheim.fandom.com/wiki/Food)

前期可以從以下組合開始，再依物資調整：

- **採集與走路**：熟野豬肉、覆盆莓、蘑菇。
- **戰鬥前**：熟野豬肉、熟鹿肉，再配一種莓果或蘑菇。

這些是容易取得的入門搭配，不是固定最佳解。查看食物的生命、體力及持續時間，保留足夠體力來閃避與撤退。烹飪時不要離開太久，肉烤熟後仍留在架上會變成煤炭。[烹飪架](https://valheim.fandom.com/wiki/Cooking_station)

### 出門前取得「休息充足」

在安全、有遮蔽且靠近火源的位置休息，確認狀態列出現 **Rested** 再出發。這個效果能明顯提高生命與體力回復，持續時間與舒適度有關。第一間小屋先求能穩定取得效果，之後再添家具。[休息充足](https://valheim.fandom.com/wiki/Rested)

### 留一段體力給撤退

攻擊、奔跑、跳躍、游泳和格擋都會消耗體力。遇敵前先停止長距離衝刺，攻擊幾次後觀察餘量，必要時退開回復。濕冷狀態會拖慢恢復，不適合空腹冒雨遠征。[體力機制](https://valheim.fandom.com/wiki/Stamina)

<a id="base"></a>
## 4. 小屋與工作臺

第一間小屋建議只放必要設備，等補給穩定再擴建。

| 設備 | 用途 | 新手要確認的事 |
| --- | --- | --- |
| 工作臺（Workbench） | 製作與修理基礎裝備。 | 有屋頂與足夠遮蔽，能正常開啟製作介面。 |
| 床（Bed） | 設定復活點、睡到隔天。 | 放下後還要互動認領，建好不代表已設定。 |
| 營火（Campfire） | 保暖、烹飪與協助休息。 | 有木材燃料，火上方有排煙空間。 |
| 烹飪架 | 烤肉。 | 位於燃燒的火源上方，熟了及時取下。 |
| 箱子 | 存放建材、食物與備用物資。 | 建議分開收納，家中留一份取物用補給。 |

工作臺可用後，開啟介面並點選修理按鈕，直到裝備修好。**修理不消耗材料**，不必因耐久歸零就重做工具。若無法修理，確認使用的是對應製作站，且站點等級足夠。[工作臺](https://valheim.fandom.com/wiki/Workbench)

睡覺還需要附近有火、沒有敵人干擾，角色也不能處於濕身狀態。不能入睡時，先讀取畫面提示再補設備。[床與復活點](https://valheim.fandom.com/wiki/Bed)

營火會產生煙，角色吸入煙霧會受傷。可以在火源上方留向外通的煙道，頂部另設遮雨空間，避免把火完全封在低矮屋內。完成後站到床與工作臺旁，觀察是否冒出煙燻狀態、火是否持續燃燒，再決定配置是否可用。[營火](https://valheim.fandom.com/wiki/Campfire)、[煙燻效果](https://valheim.fandom.com/wiki/Smoked)

## 5. 探索與戰鬥習慣

- **先走短程往返路線**：標記住處、資源與洞穴入口，背包快滿或食物不足就回家。
- **先在青青草原練習**：熟悉攻擊、格擋與翻滾。遇到不熟悉的敵人，先看攻擊動作，再找空檔反擊。
- **一次處理少量敵人**：避免在體力見底時被包圍，打不過就沿熟悉路線撤退。
- **白天探索，夜晚整備**：夜間更容易遇到危險，前期不必勉強趕路。
- **保持容易回岸的距離**：游泳消耗體力，先沿岸找路，避免為了抄近路橫越大片水域。
- **砍樹時留意倒向與滾木**：保留退路，不要站在倒木下坡側，也避免讓同伴站在落點。
- **黑森林先認路，其他生態域先避開**：巨魔、熊與成群敵人都可能讓初期裝備難以應付，不要把洞穴當成安全避難所。

以上是保守的入門建議。控制方式請看遊戲「設定」中的按鍵配置，PC 預設可用左鍵攻擊、右鍵格擋，格擋時按跳躍進行翻滾，重新綁定或控制器操作則以介面為準。[控制方式](https://valheim.fandom.com/wiki/Controls)、[探索提醒](https://valheim.fandom.com/wiki/How_to_play)、[黑森林](https://valheim.fandom.com/wiki/Black_Forest)

## 6. 死亡後如何取回裝備

一般死亡懲罰下，角色會掉落攜帶物品並損失部分技能進度。物品留在墓碑內，復活後可以回去取回。世界設定會改變懲罰，先確認自己的世界並非高懲罰模式。[死亡懲罰設定](https://valheim.fandom.com/wiki/World_Modifiers)

1. 先看地圖死亡位置，判斷路程、地形與敵人。
2. 在家吃備用食物、取得 Rested，必要時帶備用武器或找同伴協助。
3. 背包留空間，也避免裝滿重物，讓墓碑內的物品容易一次取完。
4. 接近後先引開或處理敵人，再開啟墓碑取物。
5. 取回後先撤到安全處，確認武器、防具已重新裝備。

完全清空墓碑後會取得短暫的 **Corpse Run** 效果，便於撤離。把它當成逃生機會，取物完成後先整備再決定是否繼續探索。[取物機制](https://valheim.fandom.com/wiki/How_to_play)

## 7. 第一位首領 Eikthyr

### 召喚前準備

- [ ] 小屋、復活床與修理站都可正常使用。
- [ ] 有三種食物，家中另留備用份。
- [ ] 主要武器、小盾與防具已修好，能升級時先做合理升級。
- [ ] 已練習格擋或翻滾，使用弓時備妥足夠箭矢。
- [ ] 有 Rested，並熟悉祭壇與住處之間的路線。
- [ ] 準備 **兩個鹿戰利品（Deer trophy）**，不是鹿皮或鹿肉。

在出生石陣附近與 Eikthyr 的定位符文石互動，可標記最近的召喚祭壇。前往地圖上標記的祭壇，將兩個鹿戰利品放到快捷欄，對準祭壇使用。出生石陣的首領掛鉤是勝利後懸掛戰利品的位置，不是召喚處。[Eikthyr 召喚與獎勵](https://valheim.fandom.com/wiki/Eikthyr)

### 戰鬥時的簡單原則

先觀察鹿角攻擊與雷電攻擊的起手動作，用格擋、閃避或拉開距離處理。每次只在安全空檔攻擊，持續保留撤退體力。第一次挑戰的目標是掌握節奏，不必追求快速擊殺。建議挑選離主要住處有一段距離的祭壇，並先清理周圍一般敵人。

勝利後收集 **硬鹿角（Hard antler）**，用來製作鹿角鎬（Antler pickaxe）。再把首領戰利品帶回出生石陣，掛到對應位置並互動取得能力。這會開啟採礦與金屬工具的下一階段。[Eikthyr 召喚與獎勵](https://valheim.fandom.com/wiki/Eikthyr)

<a id="black-forest"></a>
## 8. 進入黑森林後的目標

不用立刻深入，先從熟悉的青青草原邊界向外探索，建立可返回修理與補給的路線。

| 目標 | 去哪裡找或如何處理 | 預期用途 |
| --- | --- | --- |
| 銅礦（Copper ore） | 黑森林中的大型銅礦脈，以鹿角鎬開採。 | 熔煉銅，推進金屬工具。 |
| 錫礦（Tin ore） | 黑森林水邊的礦點。 | 熔煉錫，供料理與青銅製作用。 |
| 焰靈之核（Surtling core） | 準備好食物、照明與武器後探索 Burial Chambers。 | 建造炭窯、熔爐等設備。 |
| 熔煉與鍛造 | 炭窯製煤，熔爐將礦石製成金屬，再於鍛造臺加工。 | 建立青銅時代的生產流程。 |

Burial Chambers 有骷髏等敵人，進入前標記入口，一次探索一條路，不熟悉時保留退回出口的路線。巨魔洞與特殊墓穴不適合作為第一次地城探索目標。[黑森林資源](https://valheim.fandom.com/wiki/Black_Forest)、[墓穴](https://valheim.fandom.com/wiki/Burial_Chambers)

在鍛造臺用 **兩份銅加一份錫製作一份青銅**，這裡指熔煉後的金屬，不是直接投入礦石。先依最缺的能力決定工具與裝備，不必一開始就追求全套青銅防具。[錫與青銅製作](https://valheim.fandom.com/wiki/Tin)

先用往返採礦、熔煉和料理把補給穩定下來，再規劃下一位首領。這份指南到此為止，後續生態域需要另外準備。

## 9. 常見問題

| 遇到的情況 | 先檢查什麼 |
| --- | --- |
| 有材料卻看不到配方。 | 是否拿過全部必要材料種類，是否在正確製作站，等級是否足夠。 |
| 工作臺放好了卻不能製作。 | 補上屋頂與遮蔽，依畫面訊息調整。 |
| 工具耐久歸零。 | 到對應製作站按修理，不必重新製作。 |
| 床不能睡。 | 是否已認領、有屋頂、附近有火，角色是否濕身，附近是否有敵人。 |
| 躺在家裡卻持續掉血。 | 檢查煙燻狀態與營火排煙，也查看是否踩到火或有敵人。 |
| 肉變成煤炭。 | 烹飪完成後放太久，下次熟了就取下。 |
| 吃了兩份同種肉，卻沒有兩格效果。 | 三格必須是不同食物，同種食物只能刷新原效果。 |
| 明明穿了防具，仍很容易死亡。 | 先看食物是否快消化完、是否有 Rested，再檢查體力及敵人所屬生態域。 |
| 要走哪裡才找得到首領。 | 與定位符文石互動後查看地圖，不必盲目沿海搜尋。 |

上述排查對應前文的食物、工作臺、床與首領機制，建議從畫面提示開始確認。

## 10. 出門前檢查表

- [ ] 吃好三種食物，帶足此次路程的補給。
- [ ] 取得 Rested，確認生命與體力狀態。
- [ ] 武器、工具及防具已修好。
- [ ] 箭矢與照明足夠，背包保留空間。
- [ ] 知道回程方向，重要位置已標記。
- [ ] 家中有備用食物與取物用裝備。
