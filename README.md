## 本機輔助目錄

以下目錄按需使用，均由 `.gitignore` 排除，包含其所有內容。

| 目錄 | 用途 |
| --- | --- |
| `.camp_codex/` | Codex / Work 的任務暫存輸出。 |
| `.camp_claude/` | Claude Code / Cowork 的任務暫存輸出。 |
| `.camp_references/` | 使用者可隨時新增或刪除文件的參考資料區，不納入 Agent 暫存清理。 |

需長期保留的知識應依任務存入「待整理區」或「主題知識」，避免依賴可隨時移除的參考文件。

## 整理方式

1. 新資料先放入「待整理區」，主題明確時也可直接歸入既有主題。
2. 先查看既有分類，再按需要於「主題知識」建立主題資料夾，名稱不加編號前綴。
3. 同一主題的筆記與手冊放在一起，內容增加後再視需要細分，或新增「參考資料」及「附件」資料夾。
4. 每份資料保留一個主要存放位置，跨主題使用連結查找，移動檔案後同步更新相關連結與索引。

檔名以具體內容命名，例如 `Git 分支操作手冊.md`。時間順序重要時才加日期，需要保留不同版次時再加版本標示。
